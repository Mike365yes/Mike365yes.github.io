# mike365yes.github.io

Web personal de Miguel Rodríguez Grande: una página de captación dirigida a cada responsable de la empresa cliente (dirección, marketing, ventas, atención al cliente, IT, operaciones, e-commerce, RR. HH.).

Web estática (HTML, CSS y JS sin dependencias) publicada con GitHub Pages desde la rama `main`.

- `index.html`: contenido
- `styles.css`: estilos
- `main.js`: pestañas por área y formulario

Para verla en local basta con abrir `index.html` en el navegador.

Mientras el contenido sea un borrador, `index.html` lleva `noindex` para que no aparezca en buscadores.
